# Практическое задание: Динамический массив (C++)

Проект реализует собственный класс динамического массива на C++ в рамках учебного задания. Задание разделено на 5 частей.

## Выполненные части
- [x] **Часть 1:** Базовый класс, выделение памяти, конструктор копирования, расширение массива (`push_back`), математические операции (сложение, вычитание).
- [ ] **Часть 2:** Исключения
- [ ] **Часть 3:** Шаблоны
- [ ] **Часть 4:** Операторы и перегрузки
- [ ] **Часть 5:** Правило трёх/пяти

## Структура проекта
* `include/DynamicArray.h` — заголовочный файл с описанием класса
* `src/DynamicArray.cpp` — реализация методов класса
* `src/main.cpp` — файл с тестами (демонстрация работы)

## Как запустить
Скомпилировать программу можно командой:
```bash
g++ -std=c++17 -Wall -Wextra src/*.cpp -o main
```
Запуск:
```bash
./main
```
