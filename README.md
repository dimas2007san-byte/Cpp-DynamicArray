# Cpp-DynamicArray

Учебный проект: реализация собственного динамического массива на языке C++.

## Структура проекта
* `include/` — заголовочный файл `DynamicArray.h` с объявлением класса.
* `src/` — реализация методов (`DynamicArray.cpp`) и точка входа с тестами (`main.cpp`).
* `CMakeLists.txt` — конфигурация сборки через CMake.

## Что реализовано

### Часть 1: Базовая структура
* Динамическое выделение и освобождение памяти в куче (конструктор и деструктор).
* Добавление элементов с автоматическим расширением вместимости в 2 раза (`push_back`).
* Методы чтения и изменения значений по индексу (`get`, `set`).
* Получение текущего размера (`get_size`) и ёмкости (`get_capacity`).

### Часть 2: Обработка исключений
В проект добавлена обработка ошибок с использованием стандартных типов из `<stdexcept>`:
* `std::out_of_range` — выбрасывается в методах `get` и `set`, если передан индекс меньше нуля или за пределами текущего размера массива.
* `std::invalid_argument` — выбрасывается в методах `set` и `push_back`, если переданное число выходит за допустимый диапазон `[-100, 100]`.
* `std::bad_alloc` — перехватывается в демонстрационной программе при попытке выделить память под заведомо невозможный размер массива через оператор `new`.

Все исключения перехватываются по константной ссылке (`const std::exception&`), а текст ошибки выводится через метод `.what()`.

## Сборка и запуск

Сборка проекта выполняется с помощью CMake:

```bash
# Создание папки для сборки
mkdir build
cd build

# Генерация файлов сборки
cmake ..

# Компиляция
cmake --build .

# Запуск программы
./main.exe
